# 🛡️ بوت حماية وإدارة المجموعات

أوامر عربية بدون سلاش: طرد، حظر، كتم (مؤقت أيضاً)، تحذير، رتب (مدير/ادمن/مميز)، رفع وتنزيل مشرفين حقيقيين مع لقب،
عدد الرسائل وتوب المتفاعلين، ايدي بالصورة والبايو، 18 قفل حماية، منع كلمات، ترحيب، قوانين، ردود مخصصة، مسح رسائل، تثبيت، وغيرها.

## التشغيل
1. @BotFather ← `/newbot` ← خذ التوكن.
2. (مهم) BotFather ← `/setprivacy` ← اختار البوت ← **Disable** حتى يقرا كل الرسائل ويحسبها.
3. انسخ `.env.example` باسم `.env` وحط التوكن.
4. `npm install` ثم `npm start`
5. ضيف البوت للمجموعة وخليه **مشرف بكل الصلاحيات** واكتب: `الاوامر`

البيانات تنحفظ بـ `data/db.json`.
للتشغيل الدائم على سيرفر: `pm2 start index.js --name group-bot`
