# 🎮 بوت صالة الألعاب — تلكرام

10 ألعاب بالأزرار + نقاط + لوحة متصدرين:
❌ إكس أو • ✊ حجرة ورقة مقص • 🔢 خمّن الرقم • 🧠 سؤال وجواب • 🔤 رتّب الكلمة
🪢 المشنقة • 🃏 الذاكرة • 💣 كاسحة الألغام • 🧩 2048 • ➗ تحدّي الحساب

## التشغيل
1. افتح @BotFather بتلكرام ← `/newbot` ← خذ التوكن.
2. انسخ `.env.example` باسم `.env` وحط التوكن:  `BOT_TOKEN=123456:ABC...`
3. نصّب Node.js 18+ وبعدين:
```
npm install
npm start
```
النقاط تنحفظ بـ `data/users.json`.

## ملاحظات
- كل لعبة بنفس الرسالة (تتحدث بالأزرار)، وما يكدر غيرك يضغط على لعبتك.
- «خمّن الرقم» و«رتّب الكلمة» تنلعب بالكتابة؛ بالكروبات لازم تطفي Privacy Mode من BotFather (`/setprivacy` ← Disable) أو تخلي البوت أدمن.
- حتى يشتغل 24 ساعة شغّله على سيرفر (VPS / Railway / Render) مثلاً: `pm2 start index.js --name games-bot`
